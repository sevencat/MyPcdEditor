# 开发计划

## 1. 产品定位

面向机器狗巡检场景的桌面小工具，处理巡检产物中成对出现的两类文件：

- **PCD**：SLAM 建出的三维点云（场景几何、障碍物、立面）
- **PGM + yaml**：同一区域的二维栅格地图（导航用 occupancy grid）

三轮能力递进：

1. **查看**（已完成）：点云与栅格地图同屏对照，快速判断地图质量。
2. **优化**（首版已完成）：点云降采样/去噪/裁剪；栅格图去毛刺、补洞、去孤岛。
3. **合并**（自动对齐已完成，手工兜底未做）：多趟巡检的点云与栅格图合成一份。
   先用 `.projected_origin` 的 UTM 锚点定初值，再用 4 自由度（yaw + 平移）加权 ICP 精配准，
   然后拼接点云（可选体素去重）与栅格（冲突优先级：占用 > 未知 > 空闲）。

## 2. 第一轮范围（只做查看）

### In

- 打开「地图包目录」（PCD + PGM + yaml + toml + projected_origin）或单个文件
- PCD 读取：`ascii` / `binary` / `binary_compressed`（LZF），含通用字段表
- 3D 点云渲染：轨道相机、高度色带 / 单色、点大小、圆形点、抽样点一键适配
- PGM(P5/P2) + yaml 的 2D 只读查看：缩放、平移、像素→世界坐标读数
- 2D 面板与 3D 视图并排，点云按世界 XY 投影叠加到栅格上（开关）
- 栅格图铺进 3D 场景当地面（开关），用来核对点云与地图的贴合
- 状态栏：点数、FPS、GL 渲染器、包围盒

### Out（本轮明确不做）

- SLAM 位姿读入、ICP/NDT 配准
- 点云合并、栅格图拼接
- 编辑（笔刷/补洞/裁剪落盘）
- 跨平台（Linux/macOS）
- 命令行批处理

## 3. 里程碑

### M0 工程骨架与 GL 打通（0.5 d）

- `net11.0` + `win-x64`，`Directory.Build.props` 统一配置
- 项目分层落地（Core / Rendering.Gles3 / App / Tests）
- 从 MilkAvalon 移植 `GlControlBase`、`GlInfo`、`Shader`（保留出处注释）
- 交付：窗口内 GL 渐变三角正常，控制台打印 `OpenGL ES 3.x` / Renderer / 扩展表

### M1 只读 IO（1.5 d）

- `PcdReader`：头解析（`FIELDS/SIZE/TYPE/COUNT` 通用展开）+ 三种 DATA
- `PcdReader.TryOpenRawXyz`：`x y z`/`float32`/`binary` 的零拷贝快路径（返回 MMF 视图 + 点数）
- `PgmReader`：P2/P5，头部空白容错
- `MapYaml`：`resolution/origin/negate/*_thresh`，`image` 字段忽略
- `MapPackage`：目录级聚合 + `projected_origin` / `jueying_id_map.toml`
- 交付：两份样例数据可读，单元测试对拍通过

### M2 查看器（3 d）

- `PointCloudView : GlControlBase`：分片上传（64 MB/片）、12 B/点、单次 DrawArrays
- 着色：高度 turbo 色带 / 单色；`gl_PointCoord` 圆形裁剪
- `OrbitCamera`：默认斜 45° 俯视、左键微调、右键平移、滚轮缩放、`F` 适配、`R` 复位
- `MapView`：WriteableBitmap 视口采样（缩小时按覆盖范围 max-pooling，不整图转 RGBA）+ 点云 XY 叠加
- 交付：16M / 32M 点数据流畅旋转，状态栏数据正确
- 地面纹理（M2c，已补做）：PGM 降采样成单张 2048 级 RGBA8 纹理铺在点云下方，
  墙线与点云墙体直接对位；实测 215 ms 构建、8 MB 显存、对帧率无影响（见 ADR-010）
- 抽样降载（M2d，已补做）：索引抽样 1/2·1/4·1/8，32 M 点 17.7 → 43 FPS（见 ADR-011）
- 分块 + 视锥剔除（M2e，已补做）：按连续点区间切 64 K 块（32 M → 496 块），
  放大到局部只提交 34% 的点，19.7 → 33~34 FPS，与 1/4 抽样叠加 54 FPS（见 ADR-012）
- 未做（可选后续）：抽样时点大小 `sqrt(step)` 补偿；更细块/可见块索引重建（收益递减，暂不做）

## 4. 后续阶段

### M3 优化算子（首版完成 2026-11-21）

算子层（Core，纯函数、可后台跑、支持取消与进度）：

- 点云 `PointCloudOps`：`VoxelDownsample`（体素质心）、`RemoveStatisticalOutliers`（k 近邻平均距离均值 + 倍数×标准差）、`CropBox`（保留/剔除盒内点）
- 栅格 `GridMorphology`：`Despeckle`（按 8 邻域占用数去散点，保薄墙）、`Close`（补洞）、`RemoveIslands`（8 连通面积阈值）；`Open` 保留但默认不用（会抹掉 1 像素宽的墙）
- 支撑：`VoxelHash`（体素键打包 + 链式哈希表 + 质心累加）、`VoxelGridIndex`（SOR 近邻网格，容量按占用格数涨）、`PcdWriter`（float32 xyz binary）、`PgmWriter`、`MapYaml.ToYaml/Save`

交互（App）：

- 工具栏「优化 ▾」菜单：点云三项、栅格三项、导出当前结果、撤销全部优化
- `ParameterDialog`：代码搭建的数值输入框（负责人/参数/范围），校验不过就留在对话框里报错
- 结果替换视图里的云 / 栅格纹理，并在状态栏给出「N → M 点」这类对比；算子跑空（删光了）则放弃替换并提示

留待后续：

- 参数预览（先看不落）、撤销栈（当前只有「撤销全部优化 = 重新加载」）、重采样裁剪、高度裁剪

### M4 合并（自动对齐已完成，手工兜底未做）

已完成：

- 对齐：`CloudAligner` 先用 `.projected_origin` 相减定初值（同 UTM zone 才行），再跑 4 自由度（yaw + xyz）加权 ICP；
  粗级 1.5 m 体素/1.5 m 对应距离 → 精级 0.5 m/0.6 m。对应点太少时保留锚点初值并说明
- 点云：`PointCloudMerger` 多份按各自变换拼成一份，可选体素去重（保留格内首点）
- 栅格：`GridMerger` 按 origin + 变换放置，范围取并集（旋转取四角 bbox），冲突优先级 占用 > 未知 > 空闲，统计重叠像素
- 编排：`MapMerger` 出 `MergeOutcome`（云 + 对齐 + 栅格 + 中文报告）；栅格合成失败只丢栅格不拖垮点云
- 界面：工具栏「合并 ▾」→ 合并另一个地图包（后台进度 + 取消）→ 报告对话框确认后才替换视图
- 保存：`MapPackageWriter` 把当前数据写成**完整地图包目录**——文件名（`jueying.pcd/pgm/yaml`）、
  `.projected_origin`、`*_id_map.toml` 全部沿用当前打开的包，导出件能被重新打开、也能继续参与下一次合并；
  写盘走「.tmp + 改名」，写一半失败不会毁掉目标目录里的旧包

留待后续：

- 无锚点（跨 zone / 手工裁剪的包）时的手工对齐（两点/两线）——当前直接拒绝并提示原因
- 一次合多个包（当前一次一个）；按时间分段的漂移插值（当前整体一个 4 自由度刚体）

### M5 手工编辑

已完成：

- **替换**：把当前结果写回**当前打开的包目录**（`优化 ▾ → 替换当前地图包`）。
  两阶段提交：先写 `.tmp`，全部成功后才把原文件改名 `*.bak`、再把新文件改名就位；
  任何一步失败整包回滚（不会「一半新一半旧」）。二次确认里列出要写什么、备份在哪。
  打开后没动过点云时跳过 pcd（零拷贝的云映射着文件，改不了名，内容也没变）。

- **3D 框选删除**：工具栏「框选 (B)」打开后左键拖出矩形，框内的点直接删掉；`Shift` + 拖 = 只保留框内。
  矩形是屏幕空间的，对应世界空间里一个四棱锥，所以逐点投影判断（不能退化成 AABB 裁剪）：
  远处的悬空黑点、近处的人影都能框。松开就动手，全删光会拒绝；换云后框自动清掉。
  撤销仍按「重新加载」兜底。

规划中：

- 笔刷删除：圆形笔刷在 3D 里连续刷（比框选更适合成片的噪声）；与框选共用投影判定，按半径筛点
- 栅格橡皮擦：在 2D 面板上刷成未知（205）或空闲，配合现有的去毛刺/补洞
- 编辑完的落地：替换原包或导出成新包（两个入口都已可用）

## 5. 风险

| 风险 | 影响 | 处置 |
|---|---|---|
| ANGLE 的 GLES 实现与桌面 GL 行为差异 | 着色器/点大小不符预期 | 只用 ES3 核心特性；`GlInfo` 打印能力表 |
| 32M 点单次上传卡顿 | 打开时 UI 冻结 | 分片上传 + 进度条；必要时先降采样预览 |
| 大 PGM（30M px）内存 | 整图 RGBA 会到 120 MB+ | 保持单通道 + 视口采样 |
| yaml `image` 为绝对路径 | 加载失败 | 按同目录 stem 匹配，忽略该字段 |
| Avalonia 包版本混用 | `TypeLoadException` | 所有 `Avalonia.*` 锁定同一版本号 |
